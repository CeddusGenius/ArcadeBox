# ArcadeBox
ArcadeBox est un concept conçu spécifiquement pour borne arcade CRT en 15 kHz sous Windows 7 avec une section SuperUser protégée. 
ArcadeBox utilise le frontend Pegasus et RetroArch pour l'émulation. Et un menu système minimaliste créer avec AutoHotKey qui remplace l'explorer de Windows.

Pour la sécurité de Windows 7, je désactive plusieurs de ses services et j'utilise le pare-feu Malwarebytes WFC pour bloquer toutes connection entrantes et sortantes non utile à l'utilisation.

Pour l'utilisation de Windows 7 j'utilise deux comptes  :
- un compte administrateur "Admin" protégé par mot de passe.
- un compte utilisateur "ArcadeBox" autologin au démarrage de la borne arcade.
